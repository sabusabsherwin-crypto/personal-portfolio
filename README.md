# Personal Portfolio

Single-page portfolio. HTML + CSS + vanilla JS, no dependencies.

## Run
Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` > **Open with Live Server**.

## Edit
- Name: `FIRST_NAME` at the top of `js/main.js`
- Email / GitHub / LinkedIn: `index.html` (Contact section)
- FoodHub screenshot: save as `assets/images/foodhub.png`
- New project: copy one `<article class="project">` block in `index.html`
- New journey milestone: copy one `<li>` in the `.timeline` list

## Deploy
Push to GitHub, then Settings > Pages > Deploy from branch `main` / root.
